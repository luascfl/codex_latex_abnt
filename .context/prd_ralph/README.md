# Ralph context

Este diretório contém o PRD canônico usado pelo Ralph para seleção de stories e execução incremental.

## Arquivo obrigatório
- `prd.json`: backlog executável em formato JSON, com status por story.

## Regras operacionais
- Executar uma story por ciclo.
- Só mover para nova story após validação técnica da anterior.
- Atualizar `.context/docs/planning_gsd/STATE.md` ao fim de cada ciclo com evidências.
